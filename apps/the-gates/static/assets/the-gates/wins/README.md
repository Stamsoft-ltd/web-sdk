# Original Gates win assets

Six original assets generated with OpenAI built-in `image_gen`:
- Sweet: turquoise sun / gold-and-obsidian frame.
- Wild: emerald winged guardian frame.
- Epic: amethyst sacred-eye frame.
- Mythic: ruby guardian-mask frame.
- Legendary: amber sun-crown / golden guardian frame.
- Coin: thick ancient gold coin with engraved sun-eye relief.

Real RGBA transparency preserved. Lossless PNG re-encoding with macOS `sips`
fixes partial Chromium decoding; dimensions and every RGBA pixel verified identical
to generation output. No Veggie Salad plaque, coin, pixel art or other visual asset retained.
Titles now use original sculpted lettering sprites: `sweet-title.png` through
`legendary-title.png`, plus `win-title.png` and `max-title.png`. English words are
baked into the artwork; accessible labels and supporting UI remain localized.
Amounts remain live count-up text. Only count-up/threshold/fountain mechanics
follow studio conventions. Original plaque/coin prompts: `provenance.json`.
Lettering and bonus crest prompts, source paths and SHA-256 checksums:
`../presentation-art-provenance.json`.
